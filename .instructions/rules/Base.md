# Be lazy, take it easy
- Don't try to put as much code as possible. Just put enough to solve the problem
- Don't try to search entire codebase by yourself for one single line or one single thing just make a terminal command and run it and find it
- You can build shell script if you have to change a specific thing in entire codebase 

# Structure
- Make sure the codebase stays in a maintainable and scalable and easily understandable structure
- Dont just spit out code. Try to understand what you are doing and put well structured code.
- DO NOT REPEAT YOURSELF. You dont have to repeat yourself. If you need a function in more then 1 places just declare it on top or write in a file and import it from there
